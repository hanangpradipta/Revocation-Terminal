# Dokumentasi per fase

Setiap dokumen berstruktur sama:

1. Ringkas dan hasil
2. Apa yang dikerjakan dan untuk apa
3. **Kesesuaian dengan Bab I–III** (bagian mana yang sesuai, bagian mana yang penambahan)
4. Mini BPS
5. Berkas dan urutan membaca
6. Penjelasan setiap fungsi (dengan nomor baris)
7. Panduan menjalankan dan cara membaca keluarannya
8. Keputusan dan catatan
9. **Uji pemahaman** sebelum lanjut ke fase berikutnya
